# UdaanPath Frontend

> **Status:** Unimplemented (Reserved for Frontend Workstream)  
> As per the Citi India Hackathon project specifications, backend APIs, recommendation engines, eligibility verifiers, and seed datasets are implemented first.

## Planned Frontend Stack
- Framework: React 18+ / Next.js or Vite + TypeScript
- Styling: TailwindCSS + Lucide Icons + Radix UI / Shadcn
- State & Data Fetching: TanStack Query (React Query) + Axios
- Charts & Roadmaps: Recharts / Mermaid / Canvas-based timeline

## Associated Frontend Branches
The following branches are tracked in Git for future frontend implementation:
- `frontend/setup`: Scaffolding, tooling, routing, API client configuration.
- `frontend/student-profile`: Student onboarding, profile management, and document checklist UI.
- `frontend/careers-roadmap`: Career discovery, recommendation cards, and interactive milestone roadmap.
- `frontend/opportunities`: Opportunity filtering, search, and deterministic eligibility status badges.
- `frontend/facilitator`: Counselor caseload management, student vulnerability view, and intervention logs.
- `frontend/integration-polish`: Responsive adjustments, accessibility (a11y), and loading states.
- `frontend/ppt-demo-assets`: Hackathon presentation slide deck, demo video assets, and screenshots.
